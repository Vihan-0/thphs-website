2. **Zero Invention Policy**: Never invent claims, statistics, awards, pass rates, or unverified facilities.
3. **Strict Placeholder Marker**: Use `[PLACEHOLDER - Reason]` for any unverified data point.
4. **No Copying Layouts**: Visual inspiration from benchmark sites (`shrewsburyindia.in`) is limited strictly to editorial whitespace, typography pacing, and photography-first storytelling. Do NOT copy layout structures or components.
